01 Background: Supervised Graph Contrastive Learning
Baseline Overview

The SGCL Premise (ACM RecSys 2025)

Standard graph recommenders rely on either BPR loss (pairwise ranking) or unsupervised InfoNCE (data augmentations).

SGCL's Innovation: Directly construct supervised contrastive pairs from interaction edges $(u, i) \sim \mathcal{E}$, treating observed edges as positive pairs and in-batch non-paired entities as negative contrast.

SGCL Objective Formulation

L_SGCL = - ∑ log [ exp(u_b^T i_b / τ) / ( ∑_j exp(u_b^T u_j / τ) + ∑_j exp(i_b^T i_j / τ) ) ]

• User SSL: Denominator contrasts user u_b against all users u_j in batch.
• Item SSL: Denominator contrasts item i_b against all items i_j in batch.
• τ = 0.2 temperature scaling.

The Core Research Question:

Does in-batch uniform edge sampling satisfy contrastive learning assumptions, or does it introduce destructive statistical and structural noise that degrades recommendation accuracy?

02 Three Structural Pathologies Discovered
Problem Diagnosis

1. Identity Collision Noise

Uniform edge batches ($B=1024$) naturally contain duplicate users and items. Default SGCL treats all non-diagonal batch entries as negatives.

Extreme Repulsive Force:
exp(1/τ) ≈ 148.41 pushes identical semantic entities apart.
• 100% of batches have collisions
• ~51.6k FN pairs/epoch in Beauty
• ~37.5k FN pairs/epoch in Toys

2. Degree Sampling Skew

The sampling probability of item $k$ in edge batches is proportional to its degree: Q(k) ∝ d_k.

Artificial Repulsion Field:
High-degree items dominate the negative denominator, starving long-tail items of contrastive gradient signal.
• Grounded in Yi et al. (RecSys '19)
• LogQ frequency calibration needed to restore catalog density

3. Missing Cross-Contrast

SGCL contrasts users-to-users and items-to-items, but never contrasts users against non-interacted items (u^T i).

Over-Smoothing:
Uniform 1/4 layer averaging in LightGCN diffuses noise across 3 sparse bipartite hops.
• Fails to set direct decision margins
• Requires geometric layer decay

03 Proposed Solutions & Mathematical Formulations
Methodology
FN-SGCL

Dynamic Identity Masking

Mask duplicate user and item IDs across distinct batch rows:

sim_u[b,j] = -∞ if u_b == u_j
sim_i[b,j] = -∞ if i_b == i_j

Eliminates ~7.6M units of false repulsive gradient mass per epoch.

Pop-FN-SGCL

LogQ Frequency Calibration

Subtract degree correction inside the negative exponent (Yi et al., 2019):

sim_i[b,j] - β · log(d_j + 1)

At β=1.0, degree bias cancels out in expectation. We adopt calibrated β=0.5.

FS-SGCL (Best)

Full-Spectrum Contrast

Cross-domain negative contrast + Geometric layer decay:

+ γ · ∑ exp(u_b^T i_j / τ - β log d_j)
e = 0.40 e^(0) + 0.30 e^(1) + ...

Includes fixed UI mask: (u_b == u_j) | (i_b == i_j).

08 Inference Normalization Discovery
Theory & Practice Gap

The Geometric Discrepancy

SGCL's loss explicitly normalizes embeddings to unit length during training:

pos_score = exp( ũ_b^T ĩ_b / τ )
ũ = u / ||u||_2, ĩ = i / ||i||_2

The Problem: Standard RecBole evaluates testing ranks using raw unnormalized dot products (u^T i), introducing vector-length distortions.

Normalized vs. Unnormalized Test

Metric Unnormalized Dot Normalized Cosine Relative Gain
NDCG@20 0.2403 0.4317 +79.6%
Recall@20 0.4496 0.5922 +31.7%
MRR@20 0.1843 0.3922 +112.8%
Insight:

SGCL's discriminative geometry lives strictly on the angular unit hypersphere. Evaluating via raw dot products artificially confounds embedding magnitude with similarity, depressing perceived performance.
